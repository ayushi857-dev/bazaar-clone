## 📌 About The Project

**Bazaar Clone** is a frontend e-commerce website project inspired by modern online shopping platforms.

The project focuses on creating an engaging shopping interface using core web development technologies.

It demonstrates practical implementation of HTML structure, CSS styling, and JavaScript-based functionality while building a real-world inspired website.

The goal was to strengthen frontend development skills through hands-on project development.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/ayushi857-dev/bazaar-clone.git
```

### 2. Navigate to Project Folder

```bash
cd bazaar-clone
```

### 3. Run the Project

Open `index.html` in your browser.

You can also use the Live Server extension in VS Code.
